# Bank of Queensland (BOQ)

> Bank of Queensland Limited (ASX: BOQ) is one of Australia's oldest banks, founded in Brisbane in 1874, and an APRA-regulated authorised deposit-taking institution (ADI). Its banking group includes ME Bank, Virgin Money Australia and BOQ Specialist. As an accredited Consumer Data Right (CDR) data holder, BOQ exposes a public, unauthenticated Product Reference Data (PRD) API conforming to the Australian Consumer Data Standards. Consumer data sharing runs through the regulated CDR / Accredited Data Recipient (ADR) model with OAuth2/OIDC (FAPI).

## APIs

- [BOQ CDR Product Reference Data API](https://www.boq.com.au/personal/help-and-support/forms-and-important-information/open-banking): Public, unauthenticated PRD API - GET /banking/products and /banking/products/{productId}. Live base: https://secure.api.boq.com.au/cds-au/v1 (confirmed HTTP 200, x-v 3).
